MSM Botanik ücretsiz web sitesi

Kullanım:
1. Bu klasördeki tüm dosyaları birlikte saklayın.
2. index.html dosyasını tarayıcıda açarak siteyi görüntüleyebilirsiniz.
3. Ücretsiz yayınlamak için klasörü GitHub Pages, Netlify veya benzeri bir statik site hizmetine yükleyebilirsiniz.

Not: Sitedeki fotoğraflar, gönderdiğiniz Instagram ekran görüntüsündeki üretim fotoğraflarından kırpılmıştır.
